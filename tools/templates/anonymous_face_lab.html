Условия и ограничения

Начальный Тест-01 — один автоматически выбранный кадр, не установленная личность. Другие кадры не объединяются с ним автоматически. Один человек должен иметь один тестовый ID. Добавление эталона к существующему ID требует ручного подтверждения.

Весь исходный ролик эталонов исключён из проверки. Разные камеры могут показывать один проход: независимость подтверждается вручную. Подбор эталонов после просмотра результатов превращает эти записи в настроечную выборку; итоговую точность надо проверять на новых проходах.

Сопоставление использует максимальное сходство с эталонами человека. Если порог превышен для нескольких ID, результат считается неоднозначным. Порог не понижается. Маленькие лица, которые прежний анализ исключил, в тест не входят. Подсчёт ведётся по наблюдениям, не по уникальным людям или проходам.

Плавность видео не измеряет скорость живого распознавания: векторы рассчитаны заранее. Модель и выбор центрального лица — контрольный вариант 320. База, реальные имена, API и рабочие камеры не используются. Снимки и векторы остаются биометрическими данными даже под условными именами.

Локальный эксперимент. Изменения не применены к рабочей системе. Отчёт содержит изображения и биометрические векторы.
